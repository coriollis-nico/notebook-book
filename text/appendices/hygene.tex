\chapter{Buenas prácticas en programación}\label{sec:lessons}

\begin{itemize}
  \item No instalar herramientas científicas globalmente

  para mantener flexibilidad, reproducibilidad, y evitar conflictos en dependencias.

  \item Crear ambientes reproducibles para cada proyecto

  con herramientas como conda.

  \item Usar \software~libre y gratuito, y usar estándares abiertos.
\end{itemize}
